# PTCGP Ranking / MARS v1.0.0

**First production-ready Tournament API release**

Released: 2026-08-28

## What changed

Pokemon TCG Pocket now uses the Limitless Tournament API as its canonical and
default acquisition source. Tournament selection is scoped by a versioned
Pocket release catalog, raw tournament evidence is stored immutably with exact
hash-validated refs, and local aggregation produces dense directional
contracts. Canonical technical deck identity is `deck_id`; `deck_name` is
display metadata.

`legacy_html` remains available only for explicit rollback and historical,
non-authoritative diagnostics. It is not a numerical-parity target, and a
Tournament API failure never triggers a silent fallback.

## Why it matters

The pipeline now cleanly separates acquisition from analysis. Event-level
evidence is frozen first, then deterministic local transformations build meta
share, matchup counts, matrices, coverage diagnostics, and MARS. Validated
canonical dense input enters the common core through the canonical dense fast
path without unnecessary legacy consolidation.

## Reproducibility

OFFLINE replay uses the exact frozen manifest and raw refs from an earlier LIVE
run. Refs are hash-validated, network calls are zero, replay progress is
reported, and the normalized and acquisition contracts are rebuilt
deterministically.

The retained `--skip-scrape` compatibility flag instead performs a no-network
downstream rebuild from saved/frozen inputs. It does not switch to
`legacy_html` and is distinct from exact Tournament API OFFLINE replay.

## LIVE freshness

Every LIVE run performs fresh `/tournaments` discovery.

- NEW tournament: fetch details, standings, and pairings.
- RECENT tournament younger than 72 hours: fetch all tournament payloads
  again.
- STABLE tournament at least 72 hours old with validated immutable raw: reuse
  that raw evidence without tournament-payload GETs.
- Invalid or missing discovery date: take the conservative fresh-details path.

The 72-hour horizon is an operational tournament-stability rule. It is not an
official Limitless tournament-ended signal and is not the HTTP response cache
TTL.

## Performance

A frozen historical B3b OFFLINE benchmark improved from 717.443 seconds to
63.633 seconds, approximately 11.27x faster end to end. This is evidence from
that benchmark environment, not a general runtime promise.

## Validation

B13, the first canonical production run, completed on 2026-08-25 for B4 —
Ruler of the Skies in Standard format:

- 1,000 tournaments discovered; 99 selected
- 9,546 participants and 27,545 pairings
- 701 canonical deck identities
- 490,700 dense directional rows (`701 * 700`)
- 40 decks on the filtered MARS axis
- 1,560 filtered directional score rows (`40 * 39`)
- 40 ranking rows and 40 coverage rows
- 80 missing pairs
- 3 HTTP 429 responses and 3 retries
- 0 surviving acquisition failures
- P1: PASS
- P4: PASS

B4 is release-window validation evidence. The published **Latest Completed
Pocket Meta remains B3b — Everyday Wonders**.

The frozen regression baseline is 337 passing tests.

## Known limitations

- A `tournament:ended` webhook is not implemented.
- The 72-hour horizon is operational, not an official tournament completion
  signal.
- Tournament API generalization to the physical Pokemon TCG is future work.
- MARS is an analytical ranking, not a tournament forecast.
